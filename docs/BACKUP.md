# バックアップ

このアプリのデータはタブレット内（IndexedDB）にしか保存されません。サーバー同期はないので、バックアップは自分で取る必要があります。

## zip の中身

設定 →「データ」→「zip で書き出す」で作られる zip には、次が入っています。

```
manifest.json               … バージョンと書き出し日時
data/profile.json           … 開始日・Before/After・校正結果
data/progress.json          … レッスンごとの完了状況
data/drillStats.json        … ドリルの点数の履歴・自己ベスト
data/drawings.json          … 描いた絵の情報（レッスンID・種類・日時など）
data/critiques.json         … AI 批評の結果
data/streak.json            … ストリーク・フリーズ
data/counters.json          … 直線・円・箱などの累計
data/settings.json          … API キー・モデル・利き手・テーマなどの設定
data/references.json        … 取り込んだ模写用画像の情報
images/drawing/<id>.webp    … 描いた絵の画像本体
images/reference/<id>.webp  … 取り込んだ模写用画像の本体
```

**API キーも `data/settings.json` に含まれます。** zip ファイルは他人に渡さない・共有フォルダで公開しないよう注意してください。

## 書き出し

1. 設定 →「データ」→「zip で書き出す」。
2. `seichotsu-backup-YYYYMMDD.zip` という名前でダウンロードされます。
3. 「最終バックアップ」の日付が更新されます（30日以上経つとホーム画面とこの日付が案内を出します）。

## 読み込み

1. 設定 →「データ」→「読み込む」→ さきほどの zip ファイルを選ぶ。
2. 「データを置き換えますか」の確認が出ます。**今のタブレットにあるデータは、読み込んだ内容にすべて置き換わります**（消えます）。心配なら、先に今のデータもバックアップしてから読み込んでください。
3. 「置き換える」を押すと数秒で反映され、進捗・ギャラリー・設定がすべて戻ります。

## 端末買い替え時の手順

1. 古い端末で、最新の状態を zip に書き出す（上記「書き出し」）。
2. zip ファイルを、AirDrop・USBケーブル・クラウドストレージなど好きな方法で新しい端末に移す。
3. 新しい端末でこのアプリを開き（[SETUP.md](./SETUP.md) の①〜②）、設定 →「データ」→「読み込む」で zip を選ぶ。
4. API キーも zip に含まれているので、通常はそのまま使えます（新しい端末用に発行し直す必要はありません）。念のため接続テストは行ってください。

## 月1回の推奨

- ホーム画面に「バックアップから30日経過しました」という案内が出たら、そのタイミングで書き出しておくと安心です。
- 毎月の Before/After 描き直し（ホームの通知）のついでに、バックアップも一緒に取る習慣にすると忘れにくいです。

## Google Drive への保存

1. 書き出した zip を、タブレットの「ファイル」アプリまたはダウンロード先から Google Drive アプリへ共有・アップロードする。
2. わかりやすいフォルダ（例: 「成長通バックアップ」）を1つ作り、そこに `seichotsu-backup-YYYYMMDD.zip` をそのまま置いていく。ファイル名に日付が入っているので、上書きせず並べて保存しておけば、古い状態にも戻せます。
3. 容量が気になってきたら、直近数か月分だけ残して古いものを削除して構いません（月1回のBefore/After記録は絵そのものがアプリ内のギャラリーにも残ります）。
