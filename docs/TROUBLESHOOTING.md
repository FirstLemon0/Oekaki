# トラブルシューティング

## ペンで描けない（指では反応するのにペンで描けない／逆）

- 設定 →「練習」→「ペン専用モード」を確認してください。オンだと、ペン（`pointerType: pen`）以外の入力は無視されます。指で描きたい場合はオフにしてください。
- ペン専用モードがオフでも描けない場合は、開発機で確認する際はマウスでの描画も許可されています。タブレット実機では、ペン先の乾電池切れ・Bluetooth接続（ペンによっては必要）・画面保護フィルムの相性を疑ってください。
- パームリジェクション（手のひらが画面に触れても反応しない機能）が効いていないと、描いている途中で線が飛ぶことがあります。[SETUP.md](./SETUP.md) の確認手順（手のひらを置いて反応しないか試す）をもう一度試してください。

## 採点が厳しすぎる（いつも低い点数が出る）

- 設定 →「採点」→「校正モード」をまだ実行していない場合は、まず実行してください。あなた自身の今の実力を基準に合格ラインを作り直します。
- それでも厳しく感じる場合は、設定 →「採点」→「合格ラインの厳しさ」を「やさしめ」に切り替えてください。
- **点数は次のレッスンへ進むかどうかには影響しません。** 「やったかどうか」で進みます。点数が低くても気にせず進んで大丈夫です。低い点数が続いたドリルは、自動的に翌日以降の復習に差し込まれます。

## AI 批評のエラーと対処

批評画面でエラーが出たときの分類と対処です。絵はエラーが出ても保存されているので、送り直すだけで大丈夫です。

1. **API キーの問題**（「API キーを確認してください」）
   キーが未設定か、無効になっています。設定 →「AI 批評」でキーを入れ直し、「接続テスト」で確認してください。Anthropic Console 側でキーが失効・削除されていないかも確認してください（[SETUP.md](./SETUP.md) ①）。

2. **混み合っている / 今日の上限**（「今は混み合っています」）
   API 側のレート制限、または設定した「1日の上限回数」に達しています。少し時間をおくか、日付が変わってから送り直してください。上限回数は設定 →「AI 批評」→「1日の上限回数」で増やせます（費用が増える点に注意）。

3. **通信できない**（「通信できませんでした」）
   Wi-Fi・機内モードなど、ネットワーク接続を確認してから送り直してください。Anthropic 側が一時的に不調な場合もあるので、しばらくしてからもう一度試すのも有効です。

4. **モデル・応答の問題**（「モデルが使えませんでした」「今回は見てもらえませんでした」「返事を受け取れませんでした」）
   - 指定したモデル ID が使えなくなっている可能性があります。設定 →「AI 批評」→「モデル」で候補（Opus 5.5 / Opus 5 / Sonnet 5）を選び直してください。
   - 「この絵には返事ができない」と言われた場合は、別の絵で試すか、もう少し描き足してから送ってください。
   - 応答の形が崩れた場合は、もう一度送るとたいてい直ります。繰り返し失敗する場合はモデル ID の入力ミスがないか確認してください。

## フォントが出ない（文字が崩れて見える）

- 初回はオンラインで一度アプリを開き、Web フォント（Zen Kaku Gothic New / Azeret Mono）が読み込まれるのを待ってください。一度キャッシュされれば、以後はオフラインでも正しく表示されます。
- 機内モードのまま初回起動した場合や、通信が不安定なまま最初のページを閉じてしまった場合にこの症状が出ることがあります。一度オンラインの状態でページを再読み込みしてください。

## 容量警告が出る

- 設定 →「データ」の「ストレージ」で、使用量と端末の上限（quota）の目安が見られます。
- 大きくなる主な原因は、描いた絵（WebP）の枚数です。定期的に [バックアップ](./BACKUP.md) を取り、ギャラリーで不要な自由お絵描きなどを見直すことを検討してください（削除機能が無い場合は、バックアップを取った上でアプリを一度アンインストール→再インストールし、必要なものだけ読み込み直す方法もあります）。
- 「永続ストレージ」がオンになっていれば、端末が容量不足時に自動でこのアプリのデータを消すことはありません（オフの場合、設定画面で状態を確認できます）。
