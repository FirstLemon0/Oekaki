# 初回セットアップ

はじめて使うときに、上から順に1回やっておけば大丈夫です。

## ① Anthropic Console で API キーを作る

このアプリの「AI 批評」機能は、あなた個人の Anthropic API キーを使います（中継サーバーはありません）。

1. https://console.anthropic.com/ で個人アカウントを作る。
2. 支払い方法を登録し、前払いクレジットを入れる。目安は **$5**。1回の批評はおおむね ¥5 前後（設定画面の「費用の目安」でも確認できます）なので、しばらくは十分もちます。減ってきたら Console から追加してください。
3. 「API Keys」からキーを発行する（`sk-ant-...` の文字列）。このキーは他人に見せないでください。
4. 発行したキーは、次の②③の設定画面でこのアプリに入力します。**キーはこのタブレットの中（IndexedDB）にだけ保存され**、リポジトリやビルド後のファイルには一切含まれません。他の端末で使うときは、その端末でもう一度入力してください。

## ② タブレットでホーム画面に追加する（PWA 化）

1. タブレットの Chrome でこのアプリの URL を開く。
2. 右上の「⋮」メニュー → 「ホーム画面に追加」（環境によっては「アプリをインストール」）を選ぶ。
3. 追加されたアイコンから起動すると、アドレスバーの無い全画面のアプリとして使えます。オフラインでも一度開いたページはそのまま動きます。

## ③ 設定を一通り確認する

アプリ内「設定」で、次を確認・入力します。

- **AI 批評**: ①で作った API キーを入力 → 「接続テスト」で確認。モデル・思考の深さ・1日の上限回数（既定3回）もここで決められます。
- **練習**: 利き手（ツールバーの位置が左右入れ替わります）、ペン専用モード（既定オン。指では線を描けません）、通知時刻。
- **外観**: テーマ（ライト/ダーク/端末に合わせる）、文字サイズ。

## ④ 校正モードを最初に1回やる

設定 →「採点」→「校正モード」から、直線・円・楕円を数本描きます。これで、あなた自身の今の実力を基準に合格ラインが決まります。あとは点数で足止めされることはなく、自己ベストとの伸びで見せる形になります。あとからいつでもやり直せます。

## ⑤ Before の1枚を描く

初回のホーム画面に出てくる案内から、好きなキャラクターを1枚、今の実力で描きます。上手さは見られません。半年後・1年後に見比べるための記録（Before）です。ギャラリーの「Before / After 比較」からいつでも見返せます。

## ⑥ 外部お絵描きアプリの導入はステージ7から

アプリ内キャンバスはドリル用です。本番の1枚絵は、ステージ7になったら外部のお絵描きアプリで描いて取り込みます。代表的な選択肢は次の3つです（ステージ7の導入レッスンでも案内します）。

- **ibisPaint X**（無料）— 手軽に始めたいなら最初の候補。機能は必要十分。
- **CLIP STUDIO PAINT**（有料・買い切り/サブスク）— レイヤー・ブラシが強力で、3Dデッサン人形も内蔵。本格的に続けるなら。
- **Krita**（無料・OSS）— PC/タブレット両対応。カスタマイズ性重視なら。

どれか1つで大丈夫です。迷ったら ibisPaint X から始めて、必要になったら乗り換えても問題ありません。
